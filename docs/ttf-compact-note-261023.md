
# Goal
ttf-compact承袭自ttf-ng-a和ttf-ng-b项目。首要目标是合并两者，使用连接器输出信号，缩小PCB面积。

次要目标是优化
1. 电源设计；
2. 增加OPA892的电压保护；
3. 增大输出限流电阻；
4. 增大BUF634A的BW电阻到90%带宽水平即可，减少静态电流；
5. 考虑给OPA892增加反馈电阻上的电容，减少振铃；

设计上应遵循最小改动原则。

## OPA892
![[images/2026-10-23 102054.png|640]]

![[images/2026-10-23 101924.png|640]]


从仿真上看，OPA892的电压范围就是BUF634A的电压范围。手册上给出的输出电压裕量是最大2V（取1kOhm负载情况），即理论上30V电压下即可满足26V摆幅，达到设计要求。

![[images/2026-10-23 102817.png|480]]

OPA892的最大工作电压是36V，绝对最大值是37V。

![[images/2026-10-23 105608.png|480]]


### 约束与决策

30V < BUF634A的电压 ~= OPA892的实际工作电压 < 稳压管工作电压（36V）= OPA892的最大电压 < OPA892的绝对最大电压（37V）

稳压管选择Nexperia BZX84-B36-QR（C7508218）作为OPA892的稳压管。电压范围略高，但是：
1. 这是瞬态保护，不是稳态，目的是保护OPA892，所以达到OPA892的标称即可；
2. BZX84-B36-QR型号，B是精度，误差范围35.50-36.70，低于OPA892的绝对最大电压；Q是车轨，有高可靠性；
3. 稳压管电压范围高方便给OPA892提供超过理论临界30V的电压；可以比之前的方案降低1.4V-2V至33V-33.6V；

BUF634A使用二极管串联减少电压，选择Nexperia BAV99,215（C2500）；可考虑增加去耦电容；

OPA892的输出在上一板已经增加了220欧姆的电阻限流，不需要再修改；
